## 现场培训 / 汇报演示脚本

### 第一幕：集团态势

讲解：系统不是单企业 BI，而是集团级数字孪生作战室。地图上的每个节点都是一家下属企业，集团 AI 持续接收经营、科技、监管和风险数据。

### 第二幕：经营分析

进入 `02 经营分析`。

依次点击：

```text
综合评分
基础得分
经营得分
科技得分
监管得分
```

说明四象限：

```text
X = 经营得分
Y = 基础得分
Bubble Size = 综合评分
```

点击一个企业 Bubble，系统自动切换到该企业的数字画像。

### 第三幕：企业画像

点击顶部 CURRENT，可以搜索任意企业。

点击四个画像节点：

```text
基础画像
经营画像
科技画像
监管画像
```

重点演示经营画像：

```text
营业收入
净利润
净资产
ROE
```

切换指标，展示：

- 5年历史
- AI预测
- 集团排名
- Honeycomb

再点击 Honeycomb 中另外一家企业，展示系统联动。

### 第四幕：指标全景

进入 `08 指标全景`。

说明这里是集团指标数据中枢：每个指标都有独立历史、预测、横向比较和全企业分布。

### 第五幕：投资分析

进入 `04 投资分析`。

左侧切企业；中央点击 Sunburst：

```text
新能源 -> 储能 -> 项目
```

然后返回上一级。

### 第六幕：数字孪生

进入 `05 数字孪生`。

说明浏览器以高帧率表现数据流，Python只发送真实业务状态。

### 第七幕：AI Monitor

进入 `06 AI监控`。

点击：

```text
触发演示预警
```

等待自动弹窗与中文播报。

### 第八幕：AI决策

选择进入 AI 分析。

观察：

1. AI Core 加速
2. 诊断步骤依次完成
3. 因果图形成
4. Option A/B/C 顺序出现
5. Monte Carlo 从 0 到 5000
6. AI 推荐方案高亮
7. 管理人员最终确认

强调：AI提供分析与方案，最终政治/经营责任仍由管理人员决定；系统记录决策审计。

### 第九幕：语音

点击底部 AI READY，展开助手。

说或输入：

```text
分析上海分公司最近利润为什么下降
```

系统会识别企业、指标和操作意图并切换相应场景。
