## v4 相对 v3.1 的关键修复

- AI Assistant 不再固定覆盖右下角业务内容，改为可展开 Drawer。
- 删除四象限 Safari 下会漂移的 CSS scale 空心环，改为 SVG 半径动画。
- 四象限改为 X=经营得分、Y=基础得分。
- Bubble 大小由综合评分归一化驱动，显著放大以适配大屏。
- Bubble 可点击并自动进入对应企业画像。
- 经营分析排名改为综合/基础/经营/科技/监管五维。
- 企业画像支持全局企业搜索。
- 企业画像恢复基础/经营/科技/监管四画像业务结构。
- 四画像均支持深度弹窗、4项指标、5年趋势、AI预测、Honeycomb。
- 新增完整 `08 指标全景`。
- 投资分析删除中间排名，改为左企业列表 + 中大型交互 Sunburst + 右投资详情。
- Sunburst 恢复点击与下钻，不再是纯静态 Canvas。
- 投资右侧 Grid 行数重新设计，修复 KPI/柱图重叠。
- 指标数据扩展到 18 家企业、18 个指标、60 个月。
- 保留并强化 Digital Twin、AI Monitor、AI Decision、SSE、TTS、语音助手。
