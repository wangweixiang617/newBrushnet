## 集团作战室现场演示脚本

### 1. 开场

打开 `/war-room`，保持 AUTO 模式，让大屏自动巡航。

讲解重点：

> 这不是单纯的数据看板。平台把集团、分公司、财务、经营、人力、投资、项目和风险统一抽象为企业数字孪生，并由后台 AI Monitor 持续扫描。

### 2. 集团态势

展示全国战略态势图，点击华东能源分公司。

强调：

- 大屏所有分析模块围绕“当前企业”联动；
- 状态点、趋势、排行、画像、Twin 都来源于同一数据上下文。

### 3. 企业画像

切到企业画像。

讲解：

- 中间是企业核心；
- 周边是八个能力域；
- 雷达和历史趋势同步更新；
- 企业画像不是静态标签，而是随数据变化的数字 DNA。

### 4. Digital Twin

切到数字孪生。

讲解：

> 数据从 DATA HUB 进入不同 Twin，再汇聚到 AI CORE。浏览器端使用 60 FPS 动画表达业务状态，而不是让 Python 逐帧控制，所以适合长时间投屏。

### 5. AI 预警

进入 AI 监控，点击“触发演示预警”。

等待弹窗和自动播报。

讲解：

> 真实环境中这里不是人工点击，而是后台 MonitorEngine 根据预设阈值或未来接入的异常检测模型自动触发。

### 6. AI 诊断

进入 AI 决策。

让大屏依次展示：

```text
历史数据
集团比较
结构分析
相似事件
原因链
方案生成
```

讲解：

> AI 不直接跳到答案，而是把决策链条可视化，管理层可以看到系统当前分析到了哪一步。

### 7. 方案仿真

展示 Option A / B / C 和 Monte Carlo。

强调：

- 每个 Option 都是一个真实结构化对象；
- Python 后台执行 NPV 和 Monte Carlo；
- 前端只把计算结果用收敛动画展示；
- 最终决策仍由管理人员确认。

### 8. 语音控制

使用 Chrome / Edge，点击 AI Assistant，说：

```text
分析上海分公司为什么利润下降
```

或者：

```text
进入数字孪生
查看员工情绪
模拟第二个方案
```

### 9. 收尾

打开 `/control`，展示控制端和大屏端分离。

强调：

> 真正作战室不应该让管理人员直接在 4K 大屏上寻找小按钮，所以大屏负责展示，笔记本/平板负责控制，两端共享同一个 Python Scene State。
